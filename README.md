# sitemaxxing-site

Website for [Sitemaxxing](https://github.com/Malchiior/sitemaxxing): public landing page, protected reports and handoffs, and private owner design workspaces. Next.js with private Vercel Blob storage.

Owners open a short-lived link from REDESIGN, ASSETS or PACKAGE after a measured audit. Standard reports and ZIP packaging do not require image-generation credits. Optional OpenAI image generation uses a provider key entered on the website, explicit per-request approval, sample approval and a bounded attempt allowance. Report viewing codes cannot authorize generation. Paid Sitemaxxing credits and Latch image generation are not enabled.

See [the release and operating notes](docs/studio-release.md) for environment variables, security boundaries, billing limits, tests and rollback.

```
npm install
npm run dev
```
